# دفتر الذكريات

دفتر ذكريات رقمي تفاعلي — مخصص لمسؤول ميديا أسر صناع الحياة بالجامعات المصرية.

## الفكرة

موقع ويب تفاعلي يتيح للمتطوعين والزملاء كتابة رسائل وذكريات توجه لمسؤول الميديا. الموقع يوفر تجربة تشبه فتح دفتر ذكريات حقيقي.

## التقنيات

- **Next.js 15** — App Router
- **TypeScript**
- **Tailwind CSS v4**
- **Supabase** — قاعدة البيانات وتخزين الصور
- **Zod** — التحقق من البيانات
- **Cairo Font** — الخط العربي

## الإعداد

### 1. تثبيت التبعيات

```bash
npm install
```

### 2. إعداد Supabase

1. أنشئ حساب مجاني على [supabase.com](https://supabase.com)
2. أنشئ مشروع جديد
3. افتح SQL Editor في لوحة التحكم
4. انسخ محتوى ملف `supabase/schema.sql` والصقه واضغط Run

### 3. إعداد متغيرات البيئة

انسخ ملف `.env.local.example` إلى `.env.local`:

```bash
cp .env.local.example .env.local
```

ثم عدّل القيم:

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=your-secure-password
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

**ملاحظة:** يمكنك العثور على المفاتيح في Supabase Dashboard > Settings > API.

### 4. تشغيل المشروع محليًا

```bash
npm run dev
```

افتح المتصفح على `http://localhost:3000`

## الصفحات

| الصفحة | الرابط | الوصف |
|--------|--------|-------|
| الرئيسية | `/` | الغلاف الرئيسي لدفتر الذكريات |
| كتابة رسالة | `/write` | نموذج كتابة الرسالة |
| تأكيد الإرسال | `/success` | شاشة التأكيد بعد الإرسال |
| دفتر الذكريات | `/memories` | عرض الرسائل المنشورة |
| تسجيل دخول المسؤول | `/admin/login` | تسجيل الدخول للوحة التحكم |
| لوحة التحكم | `/admin` | إدارة الرسائل |

## لوحة التحكم

### تسجيل الدخول

استخدم البريد الإلكتروني وكلمة المرور المحددة في `.env.local`

### وظائف لوحة التحكم

- عرض جميع الرسائل (قيد المراجعة، منشورة، مرفوضة، مخفية)
- البحث بالاسم أو الجامعة
- فلترة الرسائل حسب الحالة
- الموافقة على الرسالة
- رفض الرسالة
- إخفاء الرسالة
- حذف الرسالة
- تمييز الرسالة كمفضلة
- تصدير الرسائل إلى CSV
- عرض الإحصائيات

## حالات الرسالة

| الحالة | الوصف |
|--------|-------|
| `pending` | قيد المراجعة — لا تظهر للعامة |
| `approved` | منشورة — تظهر في دفتر الذكريات |
| `rejected` | مرفوضة — لا تظهر |
| `hidden` | مخفية — يمكن إظهارها لاحقًا |

## الأمان

- كلمة المرور لا تُخزن كنص صريح
- حماية لوحة التحكم بـ httpOnly cookie
- التحقق من المدخلات في الواجهة والخادم
- منع XSS
- فحص امتدادات وأنواع الملفات
- حد لحجم الصورة (5 ميجا)
- عدم عرض الرسائل غير الموافق عليها
